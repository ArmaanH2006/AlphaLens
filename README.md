\# AlphaLensAlphaLens is a Python stock analysis project with a FastAPI backend. It downloads market data, calculates technical indicators, generates stock recommendations, compares trading strategies, and exposes everything through API endpoints.\## Features\* Download stock data using `yfinance`\* Calculate technical indicators:&#x20; \* Daily return&#x20; \* Cumulative return&#x20; \* 50-day moving average&#x20; \* 200-day moving average&#x20; \* RSI&#x20; \* MACD&#x20; \* Bollinger Bands&#x20; \* Volatility\* Generate BUY / HOLD / SELL recommendations\* Compare trading strategies:&#x20; \* Momentum strategy&#x20; \* Mean reversion strategy&#x20; \* Buy and hold strategy\* Calculate strategy metrics:&#x20; \* Total return&#x20; \* Sharpe ratio&#x20; \* Max drawdown\* Build portfolio-level summaries\* Provide FastAPI endpoints for frontend/dashboard use\* Include API health checks, trending stocks, validation, and response-time logging\## Project Structure```textAlphaLens/│├── backend/│   └── main.py│├── data/│   ├── stock\\\\\\\_data.py│   ├── indicators.py│   ├── recommendation.py│   └── strategy.py│├── requirements.txt├── .gitignore└── README.md```\## File Breakdown\### `data/stock\\\\\\\_data.py`Downloads stock price data using `yfinance`.Main function:```pythonget\\\\\\\_stock\\\\\\\_data(ticker, period="1y")```\### `data/indicators.py`Calculates technical indicators and stock performance metrics.Main functions:```pythonget\\\\\\\_indicators(df)analyze\\\\\\\_stock(ticker)compare\\\\\\\_stocks(tickers)```\### `data/recommendation.py`Builds a recommendation score and label using Sharpe ratio, RSI, and moving average trend.Main function:```pythonrecommend(ticker)```\### `data/strategy.py`Compares three trading strategies: momentum, mean reversion, and buy and hold.Main functions:```pythoncompare\\\\\\\_strategies(ticker)portfolio\\\\\\\_summary(tickers)```\### `backend/main.py`FastAPI backend that exposes the stock analysis functions as API routes.\## Setup\### 1. Clone the repository```bashgit clone https://github.com/ArmaanH2006/AlphaLens.gitcd AlphaLens```\### 2. Install dependencies```bashpip install -r requirements.txt```\### 3. Run the backendFrom the project root:```bashpython -m uvicorn backend.main:app --reload```The backend will run at:```texthttp://127.0.0.1:8000```\## API DocumentationFastAPI automatically creates interactive API documentation.Open:```texthttp://127.0.0.1:8000/docs```\## API Endpoints\### Root```httpGET /```Confirms the backend is running.\### Health Check```httpGET /healthGET /api/health```Returns server health status.\### Analyze Stock```httpGET /analyze/{ticker}```Example:```texthttp://127.0.0.1:8000/analyze/AAPL```Returns stock metrics such as Sharpe ratio, annual return, max drawdown, RSI, volatility, and signal.\### Recommend Stock```httpGET /recommend/{ticker}```Example:```texthttp://127.0.0.1:8000/recommend/AAPL```Returns a recommendation score, BUY/HOLD/SELL label, and reasoning.\### Compare Strategies```httpGET /strategies/{ticker}```Example:```texthttp://127.0.0.1:8000/strategies/AAPL```Returns strategy metrics for:\* Momentum\* Mean Reversion\* Buy and Hold\### Compare Multiple Stocks```httpGET /compare?tickers=AAPL,NVDA,TSLA```Returns analysis for multiple tickers.\### Portfolio Summary```httpGET /portfolio?tickers=AAPL,NVDA,TSLA,MSFT,AMD```Returns portfolio-level strategy analysis.\### Trending Stocks```httpGET /api/trending```Checks a predefined list of 20 stocks and returns the stocks currently labeled as BUY signals.\## Error HandlingThe backend includes clean error handling. If a ticker is invalid or cannot be analyzed, the API returns a clean JSON error instead of crashing.Example:```httpGET /analyze/FAKESTOCKXYZ```Expected response:```json{\\\&#x20; "detail": "Could not analyze FAKESTOCKXYZ: ..."}```\## Response Time LoggingEach endpoint logs how long it took to process the request.Example terminal output:```textGET /analyze/AAPL completed in 620.45ms with status 200```The response also includes an `X-Process-Time-ms` header.\## TestingRun the backend first:```bashpython -m uvicorn backend.main:app --reload```Then test endpoints using:\* Browser\* Postman\* curl\* `test\\\\\\\_api.py`Example curl command:```bashcurl http://127.0.0.1:8000/api/health```\## NotesThis project is for educational purposes.
